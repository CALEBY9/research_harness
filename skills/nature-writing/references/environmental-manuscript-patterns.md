# 环境领域的研究论证与手稿写作范式

这是 `nature-writing` 的领域文献参考，服务于实际手稿的起草和实质改写。选篇偏向环境科学与环境管理、风光渔空间配置/效益/情景，以及 LLM、深度学习环境应用。用户博士题目是“全球风光渔一体化的空间布局优化、综合效益评估与情景模拟研究”；该背景用于选择相关范例，不替换作者本次稿件的问题、提纲或结论。

本包归纳 8 篇研究论文和 2 篇 Perspective/Progress，Nature / Nature Ecology & Evolution / Nature Communications / Communications Earth & Environment 为主要参照，Applied Energy、Resources, Conservation & Recycling、ISPRS Journal of Photogrammetry and Remote Sensing 为领域补充。属于目的性小样本，不代表期刊官方要求或全部环境研究。

用户可继续在其他方向开展完整研究。方向探索、方法、规划、分析和写作沿用通用 Research Agent 路由；本包只在当前环境领域写作需要这些实例时加载，不把博士题目作为研究范围上限。

既有写作 owner 继续负责证据、章节、语言与交付。以下是**论证实例及其可迁移关系**，不是固定段落数、必跑方法或句式模板。原文中的夸张形容词、时代性判断或宽泛背景不随期刊名自动获得推荐资格。

## 从现有材料选择最接近的论证

| 作者材料的核心 | 文献中可参考的论证关系 | 主要范例 |
|---|---|---|
| 全球/区域空间分布、资源或生产潜力 | 把“有多少、在哪里”用于判断真正限制发展的因素 | P01、P03 |
| 能源、食物、生态、成本之间的冲突 | 用可比较配置说明取舍何时能改变、代价由谁承担 | P02、P03、P04 |
| 不同未来或管理情景 | 情景差异揭示控制结果的条件，而不只是并排报告多张地图 | P02、P03、P05 |
| LLM/遥感提供新的观测或证据 | 可信的信息获取使此前难以观察的环境格局变得可检验 | P06、P07 |
| 深度学习/混合模型 | 技术改变解决了哪一个环境量估计或过程一致性问题 | P08；P09 仅提供概念背景 |

完整出处、原文位置、研究类型和不可照搬内容见 [逐篇论证卡](environmental-paper-cards.md)。可从一篇主参照及另一篇不同处理方式开始；选择多少篇取决于当前写作缺口，不把阅读十篇设为写作前置步骤。

## 1. 引言：让研究问题从已有认识中长出来

**空间潜力类。** P01 的引言先说明食物供给压力与海洋养殖机会，再把未知收紧到全球产能的范围、位置和国家差异。研究贡献不是单独的一张地图，而是利用空间证据重新判断限制发展的问题。P03 则从能源规划中忽略社会生态代价切入，说明只在水电内部选址无法回答其他技术能否替代高影响项目。可迁移的是“已有研究的分析边界为何影响一个重要判断”。

**冲突与情景类。** P02 在营养/经济收益与生物多样性压力之间建立矛盾，再解释为什么必须同时考虑养殖布局与物种分布的未来变化。P05 从海域利用动态信息的缺口进入主体决策和空间演化。两者的方法都由待解释关系引出，而不是先介绍算法家族再寻找应用。

**AI 环境应用。** P06 从野火研究的主题和地域分布问题进入文献处理能力；LLM 出现时，读者已经知道它要帮助回答什么。P08 从站点碳通量向连续空间估计的需求、现有模型的不一致进入物理约束。不同稿件可以以科学未知或方法瓶颈为主，但二者的关系需要具体。

写新段落时可借用这种推进关系：明确作者的环境对象，概括前人已经建立的认识，说明尚不能作出的判断及其后果，再引出本研究用何种证据回答。空缺只来自已核文献及作者材料，不因范例用了“未知”就给新课题制造未知。

## 2. 贡献：从完成的工作推进到新增认识

这些论文中，“绘制地图”“建立模型”“提出流程”往往是获得答案的方式；贡献还包括空间约束是否真的紧、生态压力能否随布局改变、管理目标如何改变结果、研究关注与实际环境格局是否相称。

例如，P01 的贡献落到生物适宜空间与发展限制的关系，P02 落到生产扩张与生态影响之间的可调整关系，P06 落到文献关注与实际火灾活动的差异。P08 的方法贡献则通过物理一致性和特定环境量的估计能力得到支撑。方法论文可以以能力增量为中心，无须虚构额外生态发现。

对用户稿件而言，优先找“这项结果使哪个判断变得不同”。目前只有题目、方法或方案时，可以写问题、研究目的与设计，不借用参照论文的发现补齐作者尚未得到的结果。

## 3. Results：按读者需要得到的答案组织证据

| 文献中的实际顺序 | 每一层的论证作用 | 对手稿的启发 |
|---|---|---|
| P01：适宜空间/生产潜力 → 地理与国家差异 → 需求与约束解释 | 从分布事实推进到发展瓶颈判断 | 地图之后说明格局改变了什么认识；无需先安排一个方法性能章节 |
| P02：当前生态影响 → 未来布局及生产需求下的影响比较 | 当前参照使未来比较具有含义 | 保留基准、单位和比较对象，再解释情景差异 |
| P03：受约束的资源潜力 → 电力组合/项目选择 → 系统成本与社会生态后果 | 检验保护目标是否改变方案及其代价 | 综合效益可以由连续证据连接，不必压成单一综合指数 |
| P05：情景下总体扩张 → 空间扩张形态 | 区分规模变化和格局变化 | 不把所有情景逐项复述；突出能够区分驱动条件的比较 |
| P06：研究主题/地域 → 与火灾观测及社会经济量的对应差异 | 从文本信息走向环境问题 | 抽取流程放在支撑位置，核心发现有自己的环境参照量 |
| P07：制图准确性 → 设施分布 → 生命周期减排估计 | 前一步观测可靠性支持后一步估计 | 如果误差影响后续结果，让证据依赖可见 |
| P08：空间验证 → 物理约束/气象信息贡献 → 季节表现 → 数据质量敏感性与通量图 | 分开“准不准”“为何有用”“在哪里可靠” | 方法稿按需要展示消融/诊断；普通环境实证稿不强套性能竞赛结构 |

这里的箭头是对原文功能的归纳，不是必须复制的小节顺序。结果合并讨论、单列 Discussion 或单列 Conclusion 均有真实例子。图号也不规定故事顺序；先由已有证据决定哪一幅图承担主发现、比较或解释，再配段落。

## 4. Discussion：回答发现改变了什么

P02、P03 的讨论开端集中说明布局或保护约束怎样改变原本的冲突，并继续讨论地区、可实施条件和未覆盖因素。P01 由潜力结果转向经济与治理因素。P05 进一步解释管理主体与政策目标，P08 将性能差异联系到季节动态、数据条件及已有产品。

可迁移的讨论动作是：解释主发现如何修正已有认识；比较相近研究的对象、尺度、假设或结果；指出对具体规划/管理选择的含义；把会改变解释的条件放在对应主张附近。不是重述每张图，也不强求每项观测结果都有因果机制。

已发表论文也有不宜机械模仿的处理：P04 的讨论以较宏大的创新语言开头，P07 先讨论制图的不确定性。它们是观察到的写法，不作为所有稿件的默认开头。是否先写限制，要看限制是否决定当前发现的含义。

## 5. 摘要与标题：保留最重要的关系

P01 的摘要从未知潜力推进到发展瓶颈的判断；P02 将生产需求和生态影响放在同一比较中；P03 同时呈现保护目标、技术组合与成本；P06 让工具支撑关于研究不均衡的发现；P08 则同时呈现估计能力和物理一致性。共同可参考的动作是：用少量最有辨识力的证据说明主张，而非把 Methods 和每个 Results 小节各压缩一句。

标题可以围绕作者真正支持的对象—关系—条件构造。参照论文使用不同强度的动词和情态形式：发现已得到支持、模型显示可能性、方法提供能力，所需表述不同。无需把博士题目完整塞入每篇文章标题，也不把每篇摘要写成“一体化带来多重协同”。

## 6. 中文与英文：迁移论证功能

中文起草时先讲清问题、证据和解释之间的连接；英文稿再按对应专业术语和句法表达。可迁移的是例如“已有研究解决了哪部分，剩下什么判断不能作出”，不需要逐字借用 `Here we`、`To address this gap` 或某篇论文的首句。

范例中的 DOI、数值、地区和结论属于原论文。作为新稿引用时仍需满足原有逐项证据核对；只借鉴论证结构不代表新稿应引用全部范例。P09、P10 的前瞻文章用于概念衔接，不能代替研究论文的结果证据或 IMRaD 结构。
