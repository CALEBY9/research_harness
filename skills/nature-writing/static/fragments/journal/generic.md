# Journal: generic — writing

Used when the user has not named a target journal, or the journal is not specifically modeled by another fragment.

## Defaults

- Apply Nature-leaning structure (argument chain, section jobs) without enforcing Nature's strictest length or significance-framing demands.
- Use the selected language fragment and `core/stance.md`; do not impose English output on Chinese drafting.
- If the user requests adaptation to a named journal, use its fragment within that request; a journal mention alone does not authorize unrelated restructuring.

## Context to resolve when it changes the deliverable

Reuse the established audience, section format and scope. Without a named journal,
complete a generic draft; a standalone paragraph or section does not require
submission-package intake. Ask only when an unresolved target format, word limit,
audience or requested companion item materially changes the authorized writing.
Preserve author decisions about scientific claims and substantive cuts.
